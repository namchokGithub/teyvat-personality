## ข้อมูลที่ขาด

## หมายเหตุ

- ข้อมูลหลักสรุปจาก Character Details, Character Stories, เนื้อเรื่องประกอบ และ Vision ในหน้า Profile ของแต่ละตัวละคร
- `voiceOvers` สรุปจาก Story Voice-Overs ที่เกี่ยวข้องกับบุคลิก ความสัมพันธ์ แรงจูงใจ และพฤติกรรม ไม่รวมเสียงต่อสู้สั้น ๆ ที่ไม่มีบริบทเชิงบุคลิกเพียงพอ
- `analysisNotes` เป็นข้อวิเคราะห์จากหลักฐานและไม่ควรถูกถือเป็นข้อเท็จจริงอย่างเป็นทางการ
- รายงานนี้ครอบคลุมเฉพาะไฟล์ที่ได้รับการตรวจและทำข้อมูลแล้ว ไม่ได้หมายความว่าไฟล์ lore ตัวละครอื่นผ่านการตรวจแล้ว
